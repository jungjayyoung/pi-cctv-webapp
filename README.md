# Pi CCTV WebApp

라즈베리파이와 OpenCV를 활용한 웹 기반 CCTV 프로젝트입니다.

## 🚀 기능

* 실시간 카메라 스트리밍 (Flask)
* 웹 브라우저에서 CCTV 확인
* (예정) 사람 감지 기능
* (예정) 모바일 푸시 알림

## 🛠 기술 스택

* Python
* Flask
* OpenCV
* HTML

## 📁 프로젝트 구조

```
pi-cctv-webapp/
├─ app/
│  ├─ main.py
│  └─ templates/
│     └─ index.html
├─ requirements.txt
├─ README.md
```

## ▶️ 실행 방법

```bash
python app/main.py
```

웹 접속:

```
http://127.0.0.1:5000
```
